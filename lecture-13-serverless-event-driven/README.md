# Lecture 13 — Serverless and event-driven architectures

How the cloud runs your code without servers of your own, and how services talk to each other through events instead of direct calls.

## Lecture outline

- FaaS: AWS Lambda, Cloud Functions, Yandex Functions
- EventBridge, SQS, SNS, Kafka — event buses
- State Machines: Step Functions, Temporal
- Benefits and limitations of the serverless approach
