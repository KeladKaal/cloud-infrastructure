# Лекция 14 — Защита от DDoS и сетевых атак

Лекция про то, как облачный сервис переживает атаку: чем её поглощают, где фильтруют и как замечают вовремя.

## План лекции

- Защита от DDoS и сетевых атак в облаке
- Облачные сервисы защиты: AWS Shield (Standard / Advanced), Azure DDoS Protection, Yandex DDoS Protection
- Архитектурные стратегии: rate limiting, геораспределение через CDN/Anycast, изоляция через VPC, автоматическое масштабирование
- WAF и фильтрация на уровне приложений: OWASP Top 10, правильные правила фильтрации, бот-менеджмент
- Мониторинг и реагирование: CloudWatch, GuardDuty, SIEM-интеграция, автоматизированные сценарии (автоскейлинг + блокировка по триггерам)
