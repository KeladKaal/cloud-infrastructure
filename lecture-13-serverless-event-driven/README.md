# Лекция 13 — Serverless и event-driven архитектуры

Лекция про то, как в облаке запускают код без собственных серверов и как сервисы общаются между собой через события, а не прямыми вызовами.

## План лекции

- FaaS: AWS Lambda, Cloud Functions, Yandex Functions
- EventBridge, SQS, SNS, Kafka — событийные шины
- State Machines: Step Functions, Temporal
- Плюсы и ограничения serverless-подхода
